# Vet Brain prototype

- Use only official [Tabler Icons](https://tabler.io/icons) for interface icons on every page. Do not draw substitute SVG icons or use emoji, Unicode symbols, or other icon sets.
- Reuse the prototype's existing components and icon styling when adding new UI.
- Keep all assets local so the HTML pages work when opened through `file://`.
- For Vet Brain, generate transparent-background images with natural, realistic shadows included in the image alpha. Do not simulate missing subject shadows with CSS.
- For all current and future Vet Brain feature illustrations, use one consistent family of minimal 3D objects: warm white and cyan-teal only, one clear silhouette, very few large details, rounded glossy forms, and a natural contact shadow in the transparent PNG. Keep objects comparable in visual size and weight across pages. Use the certificate and book beneath the home hero as the detail-level reference.
