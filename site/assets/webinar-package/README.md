# Изображения вебинаров Vet Brain

Девять папок по названиям вебинаров. Файлы для карточки и адаптивного первого экрана детальной страницы.

| Файл | Назначение |
| --- | --- |
| card.png | Превью карточки на главной, без изменений. |
| hero-desktop.png | Стоящий врач с пациентом и тематическим предметом на прозрачном фоне, 1086 × 1448. Для ПК от 1440 px. |
| hero-desktop-compact.png | Та же композиция, 900 × 1200. Для ПК 1280–1439 px. |
| hero-tablet.png | Та же вертикальная композиция, 768 × 1024. Для ширины 769–1279 px. |
| hero-tablet-wide.png | Расширенная полная сцена с логотипом, около 1817 × 866. Для 481–768 px. |
| hero-mobile.png | Полная исходная сцена с логотипом. Для ширины до 480 px. |

Вертикальные изображения соответствуют композиции первого экрана курса «Атопический дерматит у собак»: врач стоит и виден ниже пояса. Фон и прозрачный передний план задаются отдельно. Широкая сцена соответствует пропорциям планшетного блока курса; вокруг лица и логотипа оставлен запас для кадрирования. Карточки вебинаров не изменялись.

Палитра фоновых цветов: coral #F8485E, teal #239CB1, mint #1CDFC6, lime #98C01E, blue #6490E7, purple #9A56A3, magenta #CC4685, orange #FE6C2B.

Пример выбора файлов для первого экрана:

```html
<picture>
  <source media="(max-width: 480px)" srcset="hero-mobile.png">
  <source media="(max-width: 768px)" srcset="hero-tablet-wide.png">
  <source media="(max-width: 1279px)" srcset="hero-tablet.png">
  <source media="(max-width: 1439px)" srcset="hero-desktop-compact.png">
  <img src="hero-desktop.png" alt="">
</picture>
```

На ширине до 768 px блок изображения имеет пропорцию 1817:866 и использует object-fit: cover. На остальных ширинах прозрачный PNG размещается через object-fit: contain. Детальные страницы вебинаров уже используют эту схему.
