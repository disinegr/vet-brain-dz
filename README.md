# Локальный прототип Vet Brain

Копия главной и страницы курса «Терапия мелких домашних животных» от 30 октября 2026 года для совместных правок и передачи разработчику. HTML, стили, шрифты, изображения и мобильные правила находятся в `site/`.

## Открыть без сервера

Откройте `site/index.html` обычным двойным щелчком. Во вкладке ДПО карточка «Терапия мелких домашних животных» ведёт на локальную страницу `site/courses/100-pervykh-paczientov-terapevta/index.html`. Логотип и пункты каталога на странице курса возвращают на главную.

Ссылки на действующий сайт и другие внешние адреса отключены. Формы показывают результат только внутри прототипа и ничего не отправляют.

## Запуск через локальный сервер (необязательно)

Нужен Node.js 18 или новее. Из этой папки выполните:

```powershell
node server.mjs
```

Затем откройте <http://127.0.0.1:4174/>.

## Где править

- `site/index.html` — содержимое и структура главной.
- `site/wp-content/themes/vet-brains/assets/style/` — исходные стили, включая `home-page-responsive.css`.
- `site/local.js` — локальное поведение элементов.
- `site/courses/100-pervykh-paczientov-terapevta/` — детальная страница курса и её ресурсы.
- `site/wp-content/` и `site/assets/review-avatars/` — локальные ресурсы.
